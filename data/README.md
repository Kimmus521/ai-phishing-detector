# Dataset Guide

## Collection Status

No dataset has been downloaded yet.

## Information to Record for Each Dataset

- Dataset name and source URL
- Download date and version
- License or usage conditions
- Original label definitions
- Number of phishing and legitimate emails
- File format and available email fields
- Local storage location

## Label Policy

- legitimate: A non-phishing email.
- phishing: An email labeled as phishing by a documented source.
- spam: Keep its original label until its relationship to phishing
  has been reviewed.

## Storage

- Original files: data/raw/
- Processed files: data/processed/
- Raw and processed data must remain outside Git.
